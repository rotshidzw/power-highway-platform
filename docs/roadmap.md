# Roadmap

## Phase 0: Scaffold + Local Dev + CI
- Monorepo scaffold with pnpm + turbo
- Docker compose stack with PostGIS and Redis
- CI pipeline for lint, typecheck, test

## Phase 1: Corridors + Contracts + Ledger + Billing MVP
- Corridor and transmission line CRUD
- Wheeling contract workflows
- Append-only energy ledger
- Invoice generation pipeline

## Phase 2: Analytics + Simulations + Regulatory Dashboards
- Daily KPI rollups
- Capacity and congestion simulations
- Regulator oversight dashboards

## Phase 3: Integrations + Settlement + Reliability Services
- External IPP ingestion feeds
- Advanced market settlement
- Reliability and resilience services
